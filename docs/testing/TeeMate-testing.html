TeeMate · testing before a demo

What’s tested, and how it went

Run on 27 October 2026. Every feature, each situation it’s tested in, and the result of the latest run; then the tests that apply across the whole app; then a checklist to tap through on a phone before a demo.

32features
114situations tested
96journeys tapped through
1,323app tests
652database checks
Everything passed. 1,323 app tests and 652 database checks on the test database.

How the testing works. Journeys tap through the real app on a pretend server as each kind of person (member, organiser, captain, club office, halfway hut staff, visitor, new joiner). For every way the server can say no, each journey checks the message is seen, the screen isn’t stuck and nothing is half-saved. Same rules on both sides (29 rules) checks the pretend server keeps the real database’s rules. Database checks run on the test database as each person.

Real phones and iPad sizes (npm run test:screens) last run 11 Oct 2026, 06:43: 31 screen checks at 1 sizes, no problems.
