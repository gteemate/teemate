# Restyle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** TeeMate in the navy-and-gold look with Home as the hub, Competitions in one place, and a simpler round, keeping every function; plus member self-entry to club competitions and tick-to-count events.

**Architecture:** Stage 1 swaps the existing colour tokens and fonts so every screen restyles at once. Later stages re-lay-out screens one area at a time behind a navigation stack, reusing `api/*`, `scoring.js`, `event-scoring.js`, `card-view.js`. The two behaviour changes (self-entry, event entries) are database-first with tests.

**Tech Stack:** Vite + plain JS, vitest, Supabase Postgres (`db:migrate`, `db:test`, `db:race`), `qrcode-generator` (npm).

**Spec:** `docs/superpowers/specs/2026-10-09-restyle-design.md` · Mock-up: `mockups/restyle.html`

## Global Constraints

- Colours (fixed): night `#0f1830`, navy `#141f3b`, card `#1b2a4b`, card-2 `#22325a`, line `#2b3c63`, gold `#e3c375` (on-gold `#1a1606`), maroon `#6c1d31`, cream `#f3efe7`, ink `#e8ecf5`, muted `#9aa7c4`, live `#7fcca2`. Navy for everyone (no light mode).
- Club colours: **main** derives night/navy/card/card-2/line; **accent** = disc ring and front flag. Gold is never club-set.
- Fonts: Source Serif 4 (titles, big numbers), Source Sans 3 (everything else), from Google Fonts with system fallbacks.
- No section tab bar. Round bar = Score · [Leaderboard] · Course only on round screens.
- Every existing function stays reachable (spec table). `npm test` and `npm run db:test` green after every task.
- Each stage: preview with sample data at 375 and 320 px, commit, **stop for the user's go-ahead, push when asked**.
- Migrations from `20261009170000`. New RPCs: revoke `public, anon`, grant `authenticated`.

## Review Focus

1. A club with a light main colour (e.g. `#9fd3c7`): derived backgrounds must stay dark enough for light text (clamp).
2. Back arrow after a deep path (Home → Competitions → league board → back → back) lands where you came from, never on a blank screen.
3. A member withdraws from a self-entry league after teams were balanced: they leave their team too (captaincy cleared).
4. Event entry after hole 1 saved → refused; un-ticking an event before hole 1 removes the entry.
5. History results for events played before the event-entries change are identical before and after the migration.
